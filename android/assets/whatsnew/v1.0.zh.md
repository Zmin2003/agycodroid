agycodroid 1.0：第一个正式版。基于 cccodroid 移植而来，把 Claude Code 换成了 Google Antigravity CLI（agy）：聊天界面、终端、工具链都不变，背后跑的是官方 Antigravity CLI。登录用 Gemini API Key 或 Google 账号 OAuth；无头模式下 agy 不能中途弹窗批工具，权限靠设置里的范围规则预先放行，或用 --dangerously-skip-permissions。

## 移植

- **Antigravity CLI**：安装器从官方渠道拉取 agy 并验签（sha512），不带任何第三方改过的二进制；聊天、终端、工具链的调用都改走 agy 的 stream-json 协议，会话用 conversation_id 续接。
- **登录**：优先用 Gemini API Key（设置里填），也可以走 Google 账号 OAuth；登录流程不伪造，登不上就明说。
- **品牌**：包名 cc.agyroid，应用名、界面文案、安装器、文档全部换成 agycodroid。

## 权限说明

- agy 的无头模式不能在运行中途弹窗请示，工具默认是软拒绝；要让它能读写文件、跑命令，先在设置里配好允许的范围，或自行承担风险用跳过权限的开关。README 里写明了这个限制，不藏着。

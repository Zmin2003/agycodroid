agycodroid 1.0: the first release. A port of cccodroid that runs Google Antigravity CLI (agy) on Android instead of Claude Code: same chat UI, terminal, and toolchain, with the official Antigravity CLI behind it. Sign in with a Gemini API Key or a Google account (OAuth); in headless mode agy cannot prompt for tool approval mid-run, so permissions are pre-granted with scoped rules in settings, or with --dangerously-skip-permissions.

## The port

- **Antigravity CLI**: the installer fetches agy from official channels and verifies it (sha512), with no third-party modified binaries; chat, terminal, and toolchain calls all go through agy's stream-json protocol, with sessions resumed by conversation_id.
- **Sign-in**: Gemini API Key first (in settings), or Google account OAuth; the flow is never faked — if it cannot sign in, it says so.
- **Branding**: package cc.agyroid, with the app name, UI copy, installer, and docs all renamed to agycodroid.

## Permissions

- agy's headless mode cannot prompt for approval mid-run, so tools are soft-denied by default; to let it read files and run commands, pre-allow the scopes in settings, or use the skip-permissions switch at your own risk. The README states this limitation openly.

## Notes

- A fresh app under package cc.agyroid; it installs alongside cccodroid without interfering.
- On first launch, install the toolchain modules (about 330 MB by default, about 700 MB for all, resumable), then download the official Antigravity CLI (about 275 MB).
- Test suite: 1,606 gateway tests pass, 20 fail (all baseline/environment issues).

agycodroid 1.0.3：agy 适配版。1.0.2 在真机上暴露出一批 agy 适配缺口：模型选不了、上下文窗口拿不到、聊天里还留着走不通的 Anthropic 登录入口、装 Antigravity CLI 会被自己误杀；这一版把这些链路一次接通，并收掉第二轮的六项收尾。

## 从 1.0.2 升级

- **直接升级即可**：不用清数据；升后模型列表与上下文窗口按新链路重新拉取。
- **旧的 OpenAI 桥已删**：原来走托管桥的配置不再生效，改走 agy 直连；端侧小模型入口也已移除。
- **工具包不用换**：仍用 `devkit-2026.11.20`，不用重新下载。

## 改了什么

- **模型能选了，上下文窗口跟上了**：模型列表改从 `agy models` 拉取（带缓存与来源标注），不再只有一个写死的示例；登录 Antigravity 后自动拉取模型与上下文大小，上下文窗口改为事后学习并随会话事件下发，压缩线按真实窗口画。
- **Anthropic 登录入口已清**：登录页不再有走不通的 Anthropic 下拉与相关文案，残留的 cc 字样与文案（9 门语言）已清理，只留 Antigravity 登录。
- **任务清单接 agy**：任务清单改从 agy 的步骤更新里取，不再是摆设。
- **旧桥已删、新桥按新方案重做**：托管 OpenAI 桥修不通，按评估重做为最小可用实现（默认关闭）；旧桥接进聊天的部分已删除，组件的安装/卸载保留。
- **装 CLI 不再被自己误杀**：网关清理进程时不再按环境变量一刀切，安装 Antigravity CLI 与首次配置的子进程不会再被误杀（rc=137 的根因）；终端写 agy 配置的口子已封上，配置只走受控路径。
- **其余收尾**：端侧小模型已删除；不再编译用不上的 `libccenosys.so`（运行期仍保留兼容）；上游 cccodroid 的 82228b1 改动已移植（16 个文件）；聊天提示行不再换行挤占，工具审批按钮恢复正常大小。

- 审查评分：第二轮 90/100（通过线 85），第一轮 86/100。
- 测试套件：网关 1526 项、1513 通过、3 失败（均为已知本机环境问题：磁盘不认权限位、tar 改属主被拒、解压封顶看不到可用空间变化）、10 跳过；Java 测试全部通过（354 项）。

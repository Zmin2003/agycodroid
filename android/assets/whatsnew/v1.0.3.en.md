agycodroid 1.0.3: an Antigravity adaptation release. On real devices, 1.0.2 exposed a batch of agy gaps: no model to pick, no context window, a dead-end Anthropic login entry in chat, and the Antigravity CLI install being killed by the app itself. This release wires those paths up and finishes the six round-two follow-ups.

## Upgrading from 1.0.2

- **Just update**: no need to clear data; after updating, the model list and context window are re-fetched through the new paths.
- **The old OpenAI bridge is gone**: setups that went through the hosted bridge no longer apply — traffic goes through agy directly; the on-device small-model entry is removed too.
- **No toolchain change**: still `devkit-2026.11.20`, no re-download needed.

## What changed

- **Models can be picked, and the context window follows**: the model list now comes from `agy models` (cached, with a source label) instead of a single hard-coded example; after signing in to Antigravity, models and context sizes are fetched automatically, and the context window is learned after the fact and sent with session events, so the compaction line is drawn against the real window.
- **The Anthropic login entry is cleared**: the login page no longer has the dead-end Anthropic dropdown and its copy; leftover cc wording and copy (9 languages) is cleaned up, leaving only the Antigravity login.
- **The task list is wired to agy**: the task list now reads from agy's step updates instead of sitting there as a placeholder.
- **Old bridge deleted, new bridge rebuilt**: the hosted OpenAI bridge couldn't be fixed, so it was rebuilt as a minimal implementation following the evaluation (off by default); the old bridge's chat wiring is deleted, while component install/uninstall stays.
- **Installing the CLI is no longer killed by the app itself**: gateway cleanup no longer kills by environment variable alone, so the Antigravity CLI install and first-run child processes are no longer killed by mistake (the root cause of rc=137); the terminal's path for writing agy settings is sealed, and settings only go through the controlled path.
- **Other cleanups**: the on-device small model is deleted; the unused `libccenosys.so` is no longer built (kept at runtime for compatibility); upstream cccodroid change 82228b1 is ported (16 files); the chat hint row no longer wraps and squeezes, and the tool-approval button is back to normal size.
